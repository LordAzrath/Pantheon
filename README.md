# Pantheon: Divine Dominion

A mobile-friendly, browser-based divine tower-defense prototype.

## Play
After GitHub Pages is enabled, the game will be available at:

https://lordazrath.github.io/Pantheon/

## How to play
1. Choose a tower in the Sanctum.
2. Tap an empty glowing sigil on the battlefield to summon it.
3. Press **Begin Wave** to release the riftborn.
4. Select a placed tower to buy upgrades across its four ascension paths.
5. Use Celestial Smite, Golden Age, and Time Still when the Worldheart is threatened.

## Content
- 20 divine towers
- 4 ascension paths per tower
- 5 tiers per path (400 total upgrade tiers)
- Boss encounters every fifth wave
- Three divine abilities
- Touch-friendly battlefield and responsive layout

This is an early playable prototype. Tower upgrade paths currently use shared combat-stat effects; more tower-specific abilities, balancing, persistence, and visual effects can be added in later updates.
